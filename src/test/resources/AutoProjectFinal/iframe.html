🖼️ iFrame Practice

Practice switching into and out of frames, and interacting with elements inside them.

How to Handle iFrames in Selenium

id name CSS Selector XPath
Step 1 — Switch into the frame:
driver.switch_to.frame("practice-iframe")  ← by name or id
driver.switch_to.frame(driver.find_element(By.ID, "practice-iframe"))  ← by element
driver.switch_to.frame(0)  ← by index

Step 2 — Interact with elements inside the frame normally.

Step 3 — Switch back to main page:
driver.switch_to.default_content()  ← back to top-level
driver.switch_to.parent_frame()  ← one level up (for nested frames)

The iframe below has id="practice-iframe" and name="practiceFrame". Switch into it, fill the form, then switch back.

Switch by ID: driver.switch_to.frame("practice-iframe")
Switch by name: driver.switch_to.frame("practiceFrame")
Switch by element: driver.switch_to.frame(driver.find_element(By.CSS_SELECTOR, "iframe#practice-iframe"))
Inside frame — type in username: driver.find_element(By.ID, "iframe-username").send_keys("student")
Switch back: driver.switch_to.default_content()
