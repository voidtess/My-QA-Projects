🔍 Locator Strategy Quick Reference

Strategy Selenium / Python Example Best For
ID driver.find_element(By.ID, "username") Unique elements with an id attribute
Name driver.find_element(By.NAME, "email") Form inputs with a name attribute
Class Name driver.find_element(By.CLASS_NAME, "btn-primary") Elements sharing a CSS class
Tag Name driver.find_elements(By.TAG_NAME, "input") All elements of a specific HTML tag
Link Text driver.find_element(By.LINK_TEXT, "Form Elements") Anchor tags with exact text match
Partial Link Text driver.find_element(By.PARTIAL_LINK_TEXT, "Form") Anchor tags with partial text match
CSS Selector driver.find_element(By.CSS_SELECTOR, "input#username") Complex selections using CSS rules
XPath driver.find_element(By.XPATH, "//input[@id='username']") Any element — most powerful & flexible
