📁 File Upload

Practice interacting with file input elements — the key technique for uploading files in Selenium.

💡 Selenium File Upload Tip

The correct way to upload files in Selenium:
Do NOT click the upload button to open the OS dialog — Selenium cannot interact with native OS dialogs.

Instead, use send_keys() directly on the <input type="file"> element with the absolute file path:

element = driver.find_element(By.ID, "simple-file-input")
element.send_keys("/absolute/path/to/your/file.txt")
